# db-unza26-csc4792 — Namwala Town Council Dataset

**CSC 4792: Data Mining and Warehousing — Mini Project (Project Team #49)**
Council: Namwala Town Council, Namwala District, Southern Province, Zambia
Official site: https://www.namwalacouncil.gov.zm

## Contents

- `data/` — 7 pipe-separated (`|`) CSV files, named `db-unza26-csc4792-namwala_*.csv`
- `namwala_notebook.ipynb` — full extraction, cleaning and preprocessing pipeline
- `Namwala_Data_Description_Paper.pdf` — Data in Brief–format description paper
- `namwala_summary_charts.png` — exploratory charts generated by the notebook

## Data files

| File | Rows | Description |
|---|---|---|
| `namwala_council_profile.csv` | 26 | Council identity, location, census population, governing Acts |
| `namwala_wards.csv` | 14 | Wards with 2010 census population |
| `namwala_public_facilities.csv` | 17 | Schools, health centres, hospital, post office with coordinates |
| `namwala_cdf_empowerment_grant_2022_quarterly.csv` | 4 | Quarterly CDF disbursement totals, 2022 |
| `namwala_cdf_empowerment_grant_2022_beneficiaries.csv` | 12 | Named 2022 CDF beneficiary groups |
| `namwala_cdf_2025_26_grant_categories.csv` | 4 | 2025/26 CDF grant categories and eligibility |
| `namwala_legal_framework.csv` | 3 | Governing Local Government Acts (2019, 2023, 2026) |

## Methodology (summary)

The official council website disallows automated access via `robots.txt`. Data were
therefore compiled from verified secondary/government-open-data sources (news reporting,
Zambia Central Statistical Office census tables, the Smart Zambia PDU facility registry,
and a CDF funding-call aggregator), cleaned, and cross-checked. Full details are in the
notebook and the data description paper.
